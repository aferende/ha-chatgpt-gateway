# Legacy ChatGPT GPT Action

This page is retained for existing links. The primary v0.7.0 integration is now the [personal MCP plugin](Configuring-the-ChatGPT-Plugin).

An existing Action works only when `ENABLE_LEGACY_REST_API=true`, with a valid scoped gateway API key and the legacy OpenAPI endpoint.
REST keys are not OAuth credentials. In MCP-only mode those endpoints are absent.
Do not place the Home Assistant token in either integration.
